Proof by induction is a method for proving a result is true for an infinite number of cases (usually the positive integers) with two steps:

1. Show the result is true for one case particular. Usually  $n=1$
2. Show that if the statement is true for one case, then it is true for the next.

Combined, if we are able to show for $n=1$, $n=k$ and $n=k+1$ that the statement is true, then we able to prove that the statement is valid for all $n>0$.
