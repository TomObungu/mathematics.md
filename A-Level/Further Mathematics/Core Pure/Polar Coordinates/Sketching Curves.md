# a $r=a(1+\cos\theta)$
When sketching polar curves, it is useful to plot points for key values of $\theta$. Make a table of values for $\theta$ at multiples of $\frac{\pi}{2}$ to determine the points at which the curve meets or intersects the coordinate axes.
